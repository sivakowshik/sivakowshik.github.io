# sivakowshik.github.io

Personal portfolio of **Siva Kowshik Sripathi Panditharadyula**, AI Engineer (Azure OpenAI · RAG · Agents · Python), Melbourne.

Live site: https://sivakowshik.github.io

Plain HTML and CSS with **no JavaScript** and no build tools to install. The pages are generated by a small Python script (standard library only), and GitHub Pages serves them straight from the `main` branch.

## Files

| Path | What it is |
|------|------------|
| `build_site.py` | Generates every page. All content (skills, experience, projects) lives here. |
| `index.html` | Home page (generated) |
| `projects/*.html` | Project case studies (generated) |
| `assets/style.css` | All styling: dark navy theme, CSS-only mobile menu and animations |
| `resume.pdf` | Downloadable resume |
| `photo.jpg` | *(optional)* Profile photo. Add a square photo with this name and it replaces the "SK" initials automatically. |

## Update the site

```bash
# edit build_site.py (or assets/style.css), then:
python3 build_site.py
git add . && git commit -m "Update portfolio" && git push
```

## Notes

- The mobile menu uses the CSS `:target` selector, so it works without JavaScript.
- Scroll animations use CSS scroll-driven animations where the browser supports them, and are switched off for people who prefer reduced motion.
